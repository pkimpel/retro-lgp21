Index of retro-lgp21/software/utilities/:
LGP-21 utility programs.

Program_Input_Routine_v2_Flexowriter.ptp
    Binary tape image for PIR, the Program Input Routine, version 2.
    Copy of the tape image from
    https://github.com/rweather/lgp21-tools/blob/main/tapes/
            Program_Input_Routine_v2_Flexowriter.ptp
    courtesy of the repository owner.

    To use, load the tape image file into the Flexowriter paper-tape
    reader and follow the instructions for bootstrapping the program
    in LGP-21 Reference Manual, page 27.

retro-lgp21-PIRv2-Memory-Load.json
    LGP-21 Memory disk image containing a ready-to-run copy of the 
    Program Input Routine, version 2, in an otherwise zeroed disk image.
    This can be loaded to the retro-lgp21 emulator to quickly install
    PIRv2 using the "Load Memory" feature in the emulator's Diagnostic 
    Panel.
