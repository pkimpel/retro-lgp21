Index of retro-lgp21/software/tools/:
Miscellaneous utility scripts for the retro-lgp21 emulator environment.

lgp21-tools-Text-Tape-Image-Converter.html
    A standalong HTML page to convert the .txt ASCII paper-tape image
    files produced by Rhys Weatherly's lgp21-tools utilities. That
    image format is close the the .ptx format used by retro-lgp21, but
    differs in some incompatible ways. This page can be loaded from a
    local file system by most browsers.
